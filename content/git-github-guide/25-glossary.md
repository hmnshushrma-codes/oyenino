| Term | Meaning |
| --- | --- |
| **Branch** | A separate line of work in a repository. `main` is usually the main one. |
| **Clone** | A full copy of a repository, with its history, on your computer. |
| **Commit** | A saved version of your project, with a message, an author and a unique ID. |
| **Conflict** | When two changes touch the same lines and Git needs you to choose. |
| **Diff** | The line-by-line difference between two versions. |
| **Fast-forward** | A merge where Git only moves the branch label forward, with no merge commit. |
| **Fetch** | Download new commits from a remote without changing your work. |
| **Fork** | Your own copy of someone else's repository, on GitHub. |
| **Hash** | The unique ID of a commit, such as `252df3a`. The full ID has 40 characters. |
| **HEAD** | Where you are now: usually the latest commit of your current branch. |
| **Detached HEAD** | Looking at a commit directly instead of a branch. |
| **Issue** | A task, bug or idea tracked on GitHub, with a number like `#12`. |
| **main / master** | The usual names for a repository's default branch. |
| **Merge** | Bring commits from one branch into another. |
| **Merge commit** | A commit with two parents that joins two lines of work. |
| **origin** | The usual name for the remote you cloned from or pushed to first. |
| **Pull** | Fetch, then merge the new commits into your current branch. |
| **Pull request** | A GitHub page asking to merge one branch into another, with review. |
| **Push** | Upload your commits to a remote. |
| **Rebase** | Replay your commits on top of another branch, making new copies of them. |
| **Reflog** | Your local record of where your branches have pointed, for rescuing lost commits. |
| **Remote** | Another copy of the repository, usually on GitHub. |
| **Repository (repo)** | A project folder whose history Git tracks. |
| **Revert** | A new commit that undoes an earlier one. |
| **Squash** | Combine several commits into one. |
| **Staging area** | The list of changes picked for the next commit. Also called the index. |
| **Stash** | A shelf for unfinished edits, so you can switch branch with a clean folder. |
| **Tag** | A permanent name for one commit, such as `v1.0.0`. |
| **Tracked file** | A file Git is watching because it was added and committed. |
| **upstream** | The usual name for the original project when you work on a fork. Also: the GitHub branch your local branch follows. |
| **Working directory** | The files you see and edit in your project folder. |

Four pairs that confuse almost everyone at the start.

| These two | The short answer |
| --- | --- |
| **Git** vs **GitHub** | Git is a free program on your computer that saves versions of your project. GitHub is a website that stores a copy of those versions online so you can share them and work with other people. |
| **Commit** vs **push** | A commit saves a version on your computer only. A push sends your commits to GitHub. Until you push, nobody else can see them. |
| **Branch** vs **fork** vs **clone** | A branch is a separate line of work inside one project. A fork is your own copy of someone else's project on GitHub. A clone is a copy of a project downloaded to your computer. |
| **Pull** vs **pull request** | `git pull` downloads new commits and adds them to your work. A pull request is a page on GitHub where you ask the project owner to review your changes and accept them. |

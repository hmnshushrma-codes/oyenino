# Cheat sheet

One page to keep open while you build.

## Safety checklist

- [ ] I have a second copy of my important files on another drive.
- [ ] I restored one file from that backup, to prove it works.
- [ ] My server is not opened to the internet through my router.
- [ ] Every app has its own strong password, kept in a password manager.
- [ ] I have a monthly reminder to update the server.
- [ ] I never paste passwords, keys or tokens into an AI chat.
- [ ] I check unfamiliar commands with prompt P13 before I run them.
- [ ] I shut the server down properly instead of pulling the plug.

## Words you will meet

| Word | What it means |
| --- | --- |
| Server | A computer that stays on and does jobs for other devices |
| Raspberry Pi | A small, low-power computer about the size of a phone |
| SSD | A fast storage drive with no moving parts |
| Operating system | The main software that runs a computer, such as Windows or Ubuntu |
| Terminal | A window where you type commands instead of clicking |
| SSH | A safe way to use your server's terminal from another computer |
| IP address | The number that identifies a device on your network, like 192.168.1.20 |
| Router | The box from your internet provider that connects your devices |
| Docker | A tool that runs apps in sealed boxes called containers |
| Container | One app, packed with everything it needs, running on its own |
| Compose file | A small text file that tells Docker which apps to run |
| Port | A numbered door on your server that an app listens at, such as 8080 |
| Cron job | A task that runs by itself on a schedule |
| Backup | A second copy of your data, kept in a different place |
| DNS | The internet's phone book that turns names into addresses. Ad blockers like Pi-hole work here |

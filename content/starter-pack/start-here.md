# Home Server Starter Pack

This pack helps you decide if you need a home server, then gives you copy-paste AI prompts to build one step by step, even if you have never opened a terminal.

## Who this is for and how it works

A home server is a small computer in your house that stays on all day, stores your files and runs useful apps for you. This pack is for two kinds of people:

- **Curious beginners.** You want to know what it is, whether it is worth it, and what the first step looks like. No technical background needed.
- **Techies.** You want a working build path, real commands, and the mistakes to avoid.

What is inside:

1. **Beginner guide:** what a home server is, and a one-week plan.
2. **Tech guide:** the exact path I took on a Raspberry Pi 5, with commands and the problems I hit.
3. **AI prompt library:** copy-paste prompts for planning, building, fixing and staying safe.
4. **Cheat sheet:** a safety checklist and a plain-English glossary.

How to use the prompts:

1. Open any AI chat, such as ChatGPT or Claude.
2. Copy a prompt from the library and replace the [brackets] with your own details.
3. Go one step at a time. Paste back what you see on your screen, including errors, and ask what to do next.

You can write to the AI in Hinglish too. If you type in Hinglish, it usually answers in Hinglish.

## Pick your path

Not sure which one you are? Start with the Beginner guide. It takes about 10 minutes, and you can switch to the Tech guide at any time.

| Compare | Beginner path | Tech path |
| --- | --- | --- |
| For you if | You have never used a terminal, or you are not sure you need a server | You are comfortable with a command line and Docker does not scare you |
| Start with | Beginner guide, then the Cheat sheet | Tech guide, then the AI prompt library |
| Time to a first result | About 1 hour to understand, about 1 week to a first working setup | Roughly a weekend, depending on your hardware |
| Hardware | Can be an old laptop you already own | A Raspberry Pi 5 with an SSD, or any small Linux machine |
| What you get | A clear plan and one safe first app | A running server with Docker, backups and your first services |

Do not buy anything yet. Read first, decide second.
